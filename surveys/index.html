About This List

This list is the public MTUS+ Source Inventory: the original surveys harmonised in MTUS and MTUS+, with their producers, distributors, identifiers, and where the original data and documentation can be found. There is one row per survey, or per regional sample. The full workbook can be downloaded as an Excel file from this page.

  • New in MTUS+: surveys added in MTUS+ and harmonised under the full MTUS+ protocol.
  • MTUS, re-harmonised for MTUS+: earlier MTUS surveys harmonised again from the original microdata.
  • MTUS (legacy): surveys carried over from earlier MTUS releases.

Use Details in the table for the fieldwork period, study number or DOI, the original data files used, the producer's recommended citation and notes, where these are known.

A blank means the information is not yet available. "Not available online" means no public source for the original data was found. Access to the original data is set by each producer or distributor.
