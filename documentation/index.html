Legacy MTUS Documentation

Legacy MTUS files follow the variable definitions and structure of the earlier MTUS collection. Their documentation, including the MTUS Codebook, is available through the UCL Research Data Repository. To be confirmed: reference and DOI for the legacy MTUS documentation

Which Document Do I Need?

  • New to MTUS+, or moving from legacy MTUS? Start with the User Guide.
  • Need to know what a variable means or how it was built? Use the Codebook.
  • Need to know how a survey was processed, or how quality was checked? Read the Harmonisation and Quality Report and the survey's harmonisation syntax.
  • Working with ICATUS or HETUS codes for older surveys? See the Transition Guide.
  • Need the original source of a survey? Look it up in the Source Inventory or on the Surveys page.
